Design system — Foundations

Tokens for an AI-assisted refund desk. Light theme only. Every value maps 1:1 to a Tailwind v4 @theme variable, shown beside it.

v0.1 · Sep 23, 2026 Next.js App Router · TypeScript · Tailwind v4
01

Color

Cool-green neutrals carry the interface. Ink is the only action color, so status hues never compete with buttons. All text pairs meet WCAG AA (4.5:1); input borders and icons meet 3:1.

Elevation

06

Focus ring

2 px focus blue, 2 px offset, on :focus-visible only. 6.5:1 against white, and it sits outside the control so it reads on every fill.

07

Motion

Short and functional: state changes, drawers, toasts. Under prefers-reduced-motion, transitions drop to 0 ms, spinners and skeleton shimmer stop, and labels ("Processing…") carry the meaning.
